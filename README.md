# Spelbackloggen
En Android app där man kan lägga till spel, välja plattform och markera vilka man har klarat. Man kan ändra och ta bort spel också!

# Felsökning
Jag trodde först att ett spel försvann när jag lade till ett annat. Men sen märkte jag att jag hade tryckt på Ändra och Spara istället för Lägg till. Så det var inget fel i koden, jag hade bara ändrat det gamla spelet.

# Hjälpmedel
Jag använde kursmaterialet när jag behövde hjälp med koden, och AI för att förstå hur ska saker fungera. Det som hjälpte mig mest var att testa appen själv i Android Studio och felsöka för att se vad som faktiskt hände.
